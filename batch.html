Single-link builder

Prepare placement tracking links

One request per sponsored video, including multiple videos from the same creator. This page runs locally in your browser. It does not send data, store history, shorten links, or measure clicks.

Preparation is not publication. Use existing campaign and placement IDs, a current Supabase snapshot version, and explicitly approved destination hosts. Your Operations Agent must recheck those records before creating live delivery links. The example below is synthetic.

Optional placement fields: discount_code and slug. Use only values already approved; the tool never invents a redeemable code. Existing UTM parameters, duplicate placement IDs, and unapproved hosts are rejected.
