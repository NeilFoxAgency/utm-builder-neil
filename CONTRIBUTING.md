# Contributing

Thank you for improving the UTM builder.

## Guidelines

- Keep the tool fully client-side and dependency-free unless there is a strong reason otherwise.
- Prefer small, reviewable changes with a clear user benefit.
- Preserve privacy: no tracking, no server round-trips for core link generation.
- If you change CSV export behavior, keep formula-injection neutralization.
- Prefer accessible markup (labels, focus visibility, meaningful status text).

## How to propose a change

1. Open an issue describing the problem or idea, or start from an existing one.
2. Work on a descriptive branch.
3. Open a pull request explaining the user problem, approach, and how you verified the change.

## Suggested directions

- Additional campaign presets
- Batch generation from a small in-browser table
- Optional query-param preservation helpers
- Print-friendly campaign checklist
