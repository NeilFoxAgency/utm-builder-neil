UTM Builder for Creator Campaigns

Privacy-first tool for YouTube creator partnerships, outreach, discount codes, and attribution reporting. Built for Neil Fox Agency workflows. 100% client-side — no network calls, no tracking.

Best practice naming (auto-enforced):
Lowercase · underscores instead of spaces · no special characters
Prefer a stable utm_id (campaign identifier) and a placement-level utm_content (e.g. plc-creator-video-01) so multi-video creators stay distinct in reports.
Absolute http(s) URL. Scheme is added automatically if missing.
